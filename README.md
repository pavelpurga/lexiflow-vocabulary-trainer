# LexiFlow Vocabulary Trainer

Offline-first PWA для систематического изучения английской лексики B1–B2. Приложение работает без регистрации и коммерческих API: карточки, интервальные повторения, активное воспроизведение, пропуски, аудирование, статистика и личный словарь доступны локально.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm test
npm run build
npm run preview
```

## Архитектура

- React + TypeScript + Vite — интерфейс и строгая типизация.
- IndexedDB — настройки, прогресс, история, пользовательские карточки и статистика.
- Service Worker + Web App Manifest — установка как PWA и работа офлайн после первого открытия.
- SM-2 — проверенный алгоритм интервальных повторений. Для каждого слова отдельно хранятся `recognition` и `production`, поэтому узнавание не выдаётся за активное владение.
- Web Speech Synthesis API — британское или американское произношение без внешнего ключа.
- Recharts — графики фактической активности и удержания.

### Состояния карточки

Карточка начинается без прогресса. Первый ответ создаёт независимое состояние навыка: число повторений, интервал, коэффициент лёгкости, срок следующего повторения и число ошибок. `Again` возвращает карточку на короткий шаг, `Hard` сокращает рост интервала, `Good` даёт стандартный интервал, `Easy` увеличивает его. Устойчиво усвоенной карточка считается только после длительных интервалов и в recognition, и в production.

## Данные

Встроенная библиотека находится в `src/data/vocabulary.ts`. Формат `WordCard` определён в `src/types.ts`; новые карточки не требуют изменения бизнес-логики. Пользователь может добавлять собственные слова, выгружать словарь в CSV, создавать JSON backup и восстанавливать его.

Отдельная база данных не требуется: версия ориентирована на персональное бесплатное использование и сохраняет данные в IndexedDB браузера. Это также исключает ложное обещание синхронизации между устройствами. Для переноса данных используется backup/restore.

## Деплой

```bash
npm run build
```

Каталог `dist` можно разместить на Cloudflare Pages, Workers Static Assets или любом статическом хостинге. Для Cloudflare Pages: build command — `npm run build`, output directory — `dist`. SPA не требует серверных переменных окружения.

## Ограничения

- Автоматическая семантическая оценка свободно написанных предложений без AI не имитируется: базовая версия использует ручную самопроверку и эталонные контексты.
- Синхронизация между устройствами и аккаунты не заявлены: данные локальны и переносятся резервной копией.
- Интерфейс на английском отмечен beta; основная локализация — русская.
- Стартовая библиотека — тщательно подготовленный набор, а не автоматически раздутые 1 500 карточек. Архитектура готова к пополнению без изменения логики.
